# Lab 1：井字棋

## 目标

用 C 语言实现一个可以在终端中完整游玩的井字棋。

把游戏完整跑通，行为正确即可。

## 准备工作

需要的准备知识：

- 分支判断。
- 二维数组。
- 从终端读取和输出数据。

环境准备：

- 一个能编辑 C 代码的编辑器，建议 VS Code。
- VsCode的相关插件，C extention和run code
- 可用的 C 编译器和终端。

## 使用 Make 编译和运行

以下命令都需要在仓库根目录执行。

编译本节课的程序：

```bash
make lab1
```

运行编译后的程序：

```bash
./build/lab1
```

我们准备了一个demo来向你展示，你的游戏交互体验应当是怎样的。
交互式运行演示：

```bash
make lab1-demo
```

该命令会自动编译并启动程序，随后根据终端提示手动输入落子位置。你的目标是实现一样的行为。

清理构建产物：

```bash
make clean
```

修改源码后，重新执行 `make lab1` 即可编译最新代码。

## 交付目标

程序需要完成以下流程：

1. 显示一个 `3 × 3` 的空棋盘。
2. 用 > 提示玩家输入要落子的位置。
3. 将当前玩家的棋子放入对应格子。
4. 判断是否有人获胜。
5. 没有获胜时，切换玩家并进入下一回合。
6. 有人获胜时立即结束游戏；棋盘下满仍无人获胜时输出平局。

本关不要求处理错误输入。可以假设玩家输入的行、列始终在有效范围内，也不会把棋子下到已有棋子的格子上。

## 棋盘与输入格式

井字棋棋盘是 `3 × 3`，外围第一行和第一列显示坐标。玩家看到的界面类似：

```text
  1 2 3
1
2
3
>
```

输入格式为：

```text
行 列
```

例如：

```text
1 1
```

表示第 1 行、第 1 列。

注意：

- 行和列都从 `1` 开始。
- 输入顺序是先写行，再写列。
- 第一次输入后由 `o` 落子，下一次由 `x` 落子，之后交替进行。
- 参考实现的玩家符号是小写 `o` 和 `x`。

## 棋盘显示

棋盘上的空格表示该位置还没有棋子。落子以后，在对应位置显示 `o` 或 `x`。

例如连续输入：

```text
1 1
2 1
```

棋盘应显示为：

```text
  1 2 3
1 o
2 x
3
>
```

## 胜负规则

同一个玩家在以下任一方向连续占据 3 个格子时获胜：

- 横向 3 格。
- 纵向 3 格。
- 斜向 3 格。

只要某一步形成 3 连，就应立即结束游戏，不再让另一名玩家继续落子。

## 结束输出

参考实现的结束信息如下。

`o` 获胜：

```text
Winner is o
```

`x` 获胜：

```text
Winner is x
```

九步之后仍无人获胜：

```text
Game tied
```

结束时保留棋盘，并在棋盘下方输出结果。

## 一个完整的获胜示例

```text
1 1
2 1
1 2
2 2
1 3
```

对应落子顺序为：

```text
o: (1, 1)
x: (2, 1)
o: (1, 2)
x: (2, 2)
o: (1, 3)
```

最终棋盘：

```text
  1 2 3
1 o o o
2 x x
3
Winner is o
```
