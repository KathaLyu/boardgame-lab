# Lab 2：井字棋与五子棋

## 目标

把 Lab 1 的井字棋扩展成一个可以在终端中完整游玩的五子棋，同时保留井字棋。

两种棋由同一个程序启动，共用同一套下棋流程。

## 准备工作

需要的准备知识：

- Lab 1 中的分支判断。
- 二维数组。
- 从终端读取和输出数据。

环境准备：

- 一个能编辑 C 代码的编辑器，建议 VS Code。
- VS Code 的相关插件，C/C++ extension 和 Code Runner。
- 可用的 C 编译器和终端。

## 编译和运行

以下命令都需要在仓库根目录执行。

编译本节课的程序：

```bash
make lab2
```

程序根据第一个参数选择游戏：

```bash
./build/lab2 xo
./build/lab2 gomoku
```

运行井字棋行为演示：

```bash
make lab2-demo
```

运行五子棋行为演示：

```bash
make lab2-demo LAB2_GAME=gomoku
```

演示命令会自动编译并启动程序。你可以手动输入落子位置，观察你的程序应当具有的行为。

清理构建产物：

```bash
make clean
```

修改源码后，重新执行 `make lab2` 即可编译最新代码。

## 交付目标

程序需要完成以下流程：

1. 根据参数显示 `3 × 3` 的井字棋棋盘或 `15 × 15` 的五子棋棋盘。
2. 用 `>` 提示玩家输入要落子的位置。
3. 将当前玩家的棋子放入对应格子。
4. 判断是否有人获胜。
5. 没有获胜时，切换玩家并进入下一回合。
6. 有人获胜时立即结束游戏；棋盘下满仍无人获胜时输出平局。

参数无效时，程序应输出用法并退出。

## 棋盘与输入格式

两种游戏使用相同的输入格式：

```text
行 列
```

例如：

```text
8 8
```

表示第 8 行、第 8 列。

注意：

- 行和列都从 `1` 开始。
- 输入顺序是先写行，再写列。
- 和 Lab 1 一样，先手玩家是 `o`，另一位玩家是 `x`。
- 参考实现使用小写 `o` 和 `x`。

| 参数 | 棋盘 | 获胜条件 |
| --- | --- | --- |
| `xo` | `3 × 3` | 连续 3 个 |
| `gomoku` | `15 × 15` | 连续 5 个或更多 |

## 错误输入

以下情况都不算成功落子，也不会切换玩家：

- 一行没有输入两个整数。
- 行号或列号超出棋盘。
- 目标位置已经有棋子。

参考实现分别输出：

```text
Invalid input
Out of bounds
Position already taken
```

提示错误后，程序应继续等待当前玩家输入。输入结束或无法继续读取时，程序应正常退出，不能反复打印提示形成死循环。

## 胜负规则

同一个玩家在以下任一方向连续占据足够多的格子时获胜：

- 横向。
- 纵向。
- 左上到右下。
- 右上到左下。

井字棋需要连续 3 个，五子棋需要连续 5 个或更多。

只要某一步形成获胜连线，就应立即结束游戏，不再让另一名玩家继续落子。

棋盘下满仍无人获胜时，游戏结束并判为平局。

五子棋不处理禁手，也不处理专业规则中的特殊长连。连续超过 5 个棋子仍然判胜。

## 结束输出

参考实现的结束信息如下。

`o` 获胜：

```text
Winner is o
```

`x` 获胜：

```text
Winner is x
```

棋盘下满仍无人获胜：

```text
Game tied
```

结束时保留棋盘，并在棋盘下方输出结果。

## 一个完整的井字棋示例

输入：

```text
1 1
2 1
1 2
2 2
1 3
```

对应落子顺序为：

```text
o: (1, 1)
x: (2, 1)
o: (1, 2)
x: (2, 2)
o: (1, 3)
```

最终棋盘：

```text
  1 2 3
1 o o o
2 x x ·
3 · · ·
Winner is o
```
